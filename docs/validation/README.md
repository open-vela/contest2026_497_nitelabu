# 功能验证与适用范围

验证结果绑定具体配置和镜像。开发者修改源码后，应重新检查所使用的功能；板级支持与某个演示镜像启用了哪些功能是两个不同维度。

| 配置或功能 | 已有结果 | 适用范围 |
| --- | --- | --- |
| 公开构建入口 | NSH、有线网、Factory、原版数字识别、双核网络/AppFS 五项全量构建通过 | [公开复现记录](public-reproduction.json)；使用公开依赖安装，新识别镜像另有实板验证 |
| Korvo 默认组合演示 | Factory 主界面 → 原版双核数字识别 → Return；人工确认无闪烁、识别正常、返回后预览恢复 | [精确内核/AppFS 配对及验收](factory-vision.json)；双核 KERNEL/MMU，切换不需复位。公开入口全量构建通过后，显示修正版完成增量构建；尚未重跑全量构建 |
| Function 有线网 | 板载 PHY、链路、ping、TCP／UDP 接收和接口关闭／重新启用通过 | [镜像身份与数据](ethernet.json)；基础通信，未作吞吐量承诺 |
| Korvo Factory 原版本 | 实时摄像头、主界面及咖啡机显示、USB 键盘输入、系统服务与基本媒体流程已有实板记录 | 单核 FLAT 配置；无线关闭。音频存在队列溢出记录，尚无听感验收 |
| 原版独立数字识别 | 原版双核摄像头与 PIE/SIMD 识别已验收；再次核验固件和运行进度 | [精确镜像及范围](digit-stable.json)；此历史独立固件不含 Factory，继续保留用于独立演示与回退 |
| 原生服务基础 | AM／PM／WM、媒体服务以及 QuickJS／Feature 等基础能力已有专项验证 | 不等同于可安装运行完整 Quick App/RPK；仍缺匹配的 RV32 核心运行库 |
| USB Device／ADB | 专用配置下，两块自有开发板完成枚举、双向会话及 shell echo | 不属于 USB Host Factory 镜像，也不扩大为电脑直连、文件同步或认证通过 |

组合镜像的验收只覆盖上述触摸往返流程。其 SD、USB Host、ADC 按键和无线关闭；咖啡机页面、听音与长时负载未在该镜像验收。较早候选的 AM shell 客户端启动停滞记录仍保留在组合镜像记录中，不因触摸流程通过而关闭。

历史测试的原始数据与失败记录保留在本地归档。公开交付以当前配置、镜像清单和精简验证记录为导航，避免把实验输出混入日常构建目录。独立数字识别的历史性能数值只适用于其对应镜像，不作为组合镜像的性能结论。

[机器可读索引](index.json)列出当前精确镜像记录与 [历史记录](historical.json)。历史记录保留原测试字段、失败分类和已有镜像/配置哈希；9 月构建记录仅证明对应旧源码构建成功。历史源码例程不计为当前固件的独立验收。
