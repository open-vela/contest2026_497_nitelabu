# UDP Rx 1704 接收队列候选复核

候选镜像：`build1703-udp-rx-buf.sha256`，仅把网络配置的 `NET_RECV_BUFSIZE`
和 `NET_MAX_RECV_BUFSIZE` 临时设为 128 KiB，以启用 socket 接收队列。

短时 10 秒诊断曾记录 0% 丢包，但原始 300 秒、40 Mbit/s UDP Rx 负载在
1704 中出现持续退化：板端最终汇总约 0.687 Mbit/s、599612 个报文中丢失
581575（约 97%），并有 330 个乱序报文；主机客户端完整运行但末尾 ACK 超时。

结论：该大接收队列候选不能作为通过证据，网络配置已回退到原始 profile，
保留源代码和完整日志供后续定位；不能用短测 0% 丢包替代原始 300 秒结果。
