# 同环境窗口 A/B/A

自动选点镜像，BSSID 7c:39:85:2a:50:04，先记录冷ARP及主机反向请求，再用单次短UDP接收建立双向通信。以下测试均TCP发送30秒，write长度16384，只有SO_SNDBUF窗口参数变化：

| 窗口 | 板端Mbit/s | 主机Mbit/s | 两端传输量 |
|---|---:|---:|---|
|16k|3.36|3.37|12.1MiB|
|64k|6.18|6.19|22.2MiB|
|16k|3.28|3.30|11.9MiB|

64k较前后16k均值约提高86%；IOB池在每轮后恢复128/128。该短测支持扩大iperf默认socket窗口，尚不替代完整300秒结果。

冷ARP：发送5请求，格式检查无异常、SDK接受，无收到ARP回复。主机ping四次仅最后一次响应(7ms)，随后板端学习主机ARP请求，TCP可用。板端ping电脑仍不回复，不能只据ICMP判断TCP网络不可用。是否为主机ICMP防火墙待查，不修改防火墙。
