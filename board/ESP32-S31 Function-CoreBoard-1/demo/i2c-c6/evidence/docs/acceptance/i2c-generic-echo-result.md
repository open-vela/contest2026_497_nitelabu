# S31 ↔ C6 通用 I2C 通信：实测通过

日期：2026-09-19。按用户最新要求，仅验证 S31 主机与 C6 从机的通用 I2C 通信，不采用传感器读数判据。

|验证项目|结果|
|---|---|
|100 kHz，1 字节回传|8/8 一致|
|100 kHz，2 字节回传|8/8 一致|
|400 kHz，1 字节回传|8/8 一致|
|400 kHz，2 字节回传|8/8 一致|
|合计|32/32 组，64 次总线传输；无传输报错，C6 dropped=0|

包含全零、全一、交替位及其他数据模式。S31 GPIO45→C6 GPIO4（SCL），GPIO46→GPIO5（SDA），GND 共地，地址 0x68。频率为主机配置值，未使用逻辑分析仪测量波形。

## 修复

此前 C6 的读请求回调为空，没有在地址匹配后提交响应并释放时钟延展；旧响应缓冲还存在发送长度不足问题。新建独立通用夹具 `tools/esp32c6-i2c-slave`：按读请求发送数据，校验发送长度，队列保存每笔接收数据。S31 使用无传感器初始化的 `xts-flat-i2c-c6` 配置。本轮未改动 S31 I2C 驱动。
