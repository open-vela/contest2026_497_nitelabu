媒体命令（仅在1243媒体镜像、媒体配置与原文件已准备、mediad已运行时）：

```
mediatool
send all loglevel 24
open Music
prepare 0 url /data/audio_file.aac
start 0
# 等待COMPLETED ret:0后
close 0
q
```

ID必须使用open实际返回值，不得假设其他player已存在时仍为0。原1249日志中的ID为0。

准备限制：当前1425网络测试占用UART，不允许为拍摄中途刷机。1243的/data是当时媒体准备流程，不假定当前同名目录还保留媒体配置；3MiB xTS Flash有独立历史备份，不能为演示格式化。按历史准备流程在已验证卷/目录中准备素材，先核对挂载和镜像。
